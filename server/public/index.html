Sessão GUI Inativa / Tela Bloqueada

A captura de tela falhou na máquina remota. Isso geralmente ocorre em VPSs Windows quando a conexão RDP é fechada ou minimizada.

// Solução rápida (Rode no CMD da VPS):
1. Descubra o ID da sua sessão RDP:
query session
2. Desconecte do RDP mantendo a tela ativa:
tscon ID_SESSAO /dest:console
(Exemplo se o ID for 1 ou 2: tscon 1 /dest:console ou tscon 2 /dest:console)

O sistema tentará reconectar automaticamente a cada 2 segundos.
